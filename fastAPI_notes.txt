INTRODUCTION TO APIs
======================
-API (Application Programming Interface) allows communication between applications.
-Client sends a request and server sends a response.


REST ARCHITECTURE
-----------------
-REST = Representational State Transfer
-Stateless communication: The server does not remember any information about previous requests.
-Resource-based URLs: Resources are identified using URLs
-Each request contains all required information: Since REST is stateless, every request must contain all data needed for processing

Examples:
GET    /users
GET    /users/1
POST   /users
PUT    /users/1
DELETE /users/1



HTTP METHODS
------------
GET    : Retrieve data
POST   : Create data
PUT    : Update entire resource
PATCH  : Update partial resource
DELETE : Delete resource

HTTP STATUS CODES
-----------------
200 : Success
201 : Created
400 : Bad Request
401 : Unauthorized
403 : Forbidden
404 : Not Found
500 : Internal Server Error


JSON
----
-JavaScript Object Notation
-Lightweight data exchange format.
-Uses key-value pairs.

Example:
{
  "id": 1,
  "name": "John"
}

UVICORN
=======
-Uvicorn is a web server used to run FastAPI applications.
-Uvicorn acts as the driver that starts and runs the FastAPI application.
-FastAPI only defines API routes and business logic.
-It does not listen for HTTP requests by itself.
    A web server is required to:
    - Start the application
    - Listen on a port
    - Accept requests
    - Send responses
-Uvicorn performs all these above tasks.

ROUTING
========
GET Route:
@app.get("/users")

POST Route:
@app.post("/users")

PUT Route:
@app.put("/users/{id}")

DELETE Route:
@app.delete("/users/{id}")

PATH PARAMETERS
===============
Used to pass values through URL.

Example:
@app.get("/users/{id}")
def get_user(id:int):
    return {"id":id}

URL:
http://localhost:8000/users/101

QUERY PARAMETERS
================
Used for filtering and pagination.

Example:
@app.get("/users")
def get_users(page:int=1,size:int=10):
    return {"page":page,"size":size}

URL:
http://localhost:8000/users?page=1&size=10

REQUEST BODY
============
Used to send data to server.

Example:
from pydantic import BaseModel

class User(BaseModel):
    name:str
    age:int

@app.post("/users")
def create_user(user:User):
    return user

RESPONSE MODEL
==============
Used to validate and format response.

Example:
@app.get("/users/{id}",response_model=User)

Benefits:
-Validation
-Filtering
-Auto Documentation

TYPE HINTS
==========
Example:
def add(a:int,b:int)->int:
    return a+b

Benefits:
-Validation
-Better IDE Support
-Cleaner Code

PYDANTIC MODELS
===============
Used for:
-Validation
-Serialization
-Data Parsing

Example:
class Employee(BaseModel):
    name:str
    salary:float

FIELD VALIDATION
================
from pydantic import Field

class User(BaseModel):
    age:int = Field(gt=18)

Validation Rules:
gt : greater than
ge : greater than equal
lt : less than
le : less than equal

OPTIONAL FIELDS
===============
from typing import Optional

class User(BaseModel):
    phone: Optional[str] = None

NESTED MODELS
=============
class Address(BaseModel):
    city:str

class User(BaseModel):
    name:str
    address:Address

DEPENDENCY INJECTION
====================
Used for reusable logic.

Example:
from fastapi import Depends

def common():
    return "dependency"

@app.get("/")
def home(data=Depends(common)):
    return data

Benefits:
-Reusable Code
-Clean Architecture
-Loose Coupling

HEADERS
=======
from fastapi import Header

@app.get("/")
def home(token:str=Header()):
    return token

COOKIES

from fastapi import Cookie

ORM
===
ORM = Object Relational Mapping

Table ↔ Class

Advantages:
-No Raw SQL
-Easier Maintenance
-Database Independent

SQLALCHEMY MODEL
================

    __tablename__ = "employees"

    id = Column(Integer, primary_key=True)
    name = Column(String)

PASSWORD HASHING
================
Never store plain text passwords.

Example:
from passlib.context import CryptContext

pwd_context = CryptContext(
    schemes=["bcrypt"]
)

hashed_password = pwd_context.hash("admin123")

JWT AUTHENTICATION
==================
JWT = JSON Web Token

Structure:
Header.Payload.Signature

Flow:
User Login
    ↓
Generate Token
    ↓
Send Token
    ↓
Validate Token
    ↓
Access Resource

Advantages:
-Stateless
-Secure
-Scalable

MIDDLEWARE
==========
Middleware executes before and after requests.

Uses:
-Logging
-Authentication
-Monitoring

Example:
@app.middleware("http")
async def logger(request, call_next):
    response = await call_next(request)
    return response

CORS
====
Cross-Origin Resource Sharing

Required when frontend and backend run on different domains.

Example:
app.add_middleware(

    allow_origins=["*"]
)
