Variable Scopes  
===============
-Python variables has 4 scopes : LEGB

Global → variables defined outside all functions
Local → inside the current function
Enclosing → inner function accesses outer function variables
Built-in → Python's built-in names (len, print, etc.)

Note: we cann't modify the global variable inside a function
      To modify a global variable inside a function, use 'global' keyword
      
Note: inner function cann't modify the outer function variable value
      To modify variables in enclosing scope, use 'nonlocal' keyword



Data Types
==========
-A data type defines the type of value stored in a variable.

• int – Integer numbers
  Example: age = 25
           type(age)

• float – Decimal numbers
  Example: price = 99.99

• complex – Complex numbers
  Example: num = 2 + 3j

• bool – Boolean values (True or False)
  Example: is_active = True

• str – String/Text data
  Example: name = "Python"

• list – Ordered, mutable collection
  Example: fruits = ["Apple", "Mango", "Orange"]

• tuple – Ordered, immutable collection
  Example: colors = ("Red", "Green", "Blue")

• set – Unordered collection of unique values
  Example: numbers = {1, 2, 3, 4}

• frozenset – Immutable set
  Example: fs = frozenset([1, 2, 3])

• dict – Key-value pairs
  Example: student = {"name": "Sanjay", "age": 25}

• range – Sequence of numbers
  Example: nums = range(1, 6)

• bytes – Immutable binary data
  Example: b = b"Hello"

• bytearray – Mutable binary data
  Example: ba = bytearray(5)

• memoryview – Memory view object
  Example: mv = memoryview(bytes(5))

• NoneType – Represents no value
  Example: x = None

Tuple
=====
-Tuples are used to store multiple items in a single variable.
-Tuple items are ordered, unchangeable, and allow duplicate values.
 ex: fruits = ("apple", "banana", "cherry","apple")
-To determine how many items a tuple has, use the len() function:
 print(len(fruits))
-To create a tuple with only one item, you have to add a comma after the item, otherwise Python will not recognize it as a tuple.
 fruits = ("apple",)  # valid
 fruits = ("apple")  # invalid
-A tuple can contain different data types 
  tuple1 = ("abc", 34, True, 40, "male")
-Access tuple items by referring to the index number
  fruits[1]
-When specifying a range, the return value will be a new tuple with the specified items
 fruits[2:5]  
-Unpacking a Tuple
 fruits = ("apple", "banana", "cherry")
 (green, yellow, red) = fruits
-add an * to the variable name and the values will be assigned to the variable as a list
 fruits = ("apple", "banana", "cherry", "strawberry", "raspberry")
 (green, yellow, *red) = fruits
-we can loop through the tuple items by using a for loop
   for ele in thistuple:
      print(ele)
-Two built-in methods that we can use on tuples : count() , index()


List vs Tuple 
=============
List = Mutable → can be changed --> Good for changing data
Tuple = Immutable → cannot be changed --> Good for fixed data


Set
===
-Sets are used to store multiple items in a single variable
-Sets are written with curly brackets.
  ex: fruitSet = {"apple", "banana", "cherry"}
-Set items are unordered, unchangeable, and do not allow duplicate values.
-To determine how many items a set has, use the len() function
  print(len(fruitSet))
-we cannot access items in a set by referring to an index or a key  
-we can loop through the set items using a for loop
-Check if an item is present in the set
  print("orange" in fruitSet)
  print("orange" not in fruitSet)
-To add one item to a set use the add() method
-To add items from another set into the current set, use the update() method
  fruitSet = {"apple", "banana", "cherry"}
  tropical = {"pineapple", "mango", "papaya"}
  fruitSet.update(tropical)
  print(fruitSet)  # 6 items
-To remove an item in a set, use the remove(), or the discard() method
   fruitSet.discard("banana")

Note: If the item to remove does not exist, discard() will NOT raise an error.
      If the item to remove does not exist, remove() will raise an error.
-There are several ways to join two or more sets in Python.
  The union() and update() methods joins all items from both sets.
  The intersection() method keeps ONLY the duplicates.
  The difference() method keeps the items from the first set that are not in the other set(s).
  The symmetric_difference() method keeps all items EXCEPT the duplicates.        

-frozenset is an immutable version of a set.
-elements cannot be added or removed from a frozenset.
  fruits = frozenset({"apple", "banana", "cherry"})  



Dictionary
==========
-Dictionaries are used to store data values in key:value pairs.
-To determine how many items a dictionary has, use the len() 
-The values in dictionary items can be of any data type
-We can access the items of a dictionary by referring to its key name, inside square brackets
 product = {"brand": "HP","model":"ProBook","year": 2021}
 print(product["year"])
-There is also a method called get() that gives the same result
  print(product.get("year"))
-To determine if a specified key is present in a dictionary use the in keyword
-The pop() method removes the item with the specified key name    
-clear() method empties the dictionary

Method	Description
=====================
clear()	Removes all the elements from the dictionary
copy()	Returns a copy of the dictionary
fromkeys()	Returns a dictionary with the specified keys and value
get()	Returns the value of the specified key
items()	Returns a list containing a tuple for each key value pair
keys()	Returns a list containing the dictionary's keys
pop()	Removes the element with the specified key
popitem()	Removes the last inserted key-value pair
setdefault()	Returns the value of the specified key. If the key does not exist: insert the key, with the specified value
update()	Updates the dictionary with the specified key-value pairs
values()	Returns a list of all the values in the dictionary
