  fruits[1]

 fruits[2:5]

 fruits = ("apple", "banana", "cherry")
 (green, yellow, red) = fruits

 fruits = ("apple", "banana", "cherry", "strawberry", "raspberry")
 (green, yellow, *red) = fruits

   for ele in thistuple:
      print(ele)

Set
===
-Sets are used to store multiple items in a single variable
-Sets are written with curly brackets.
  ex: fruitSet = {"apple", "banana", "cherry"}
-Set items are unordered, unchangeable, and do not allow duplicate values.
-To determine how many items a set has, use the len() function
  print(len(fruitSet))
-we cannot access items in a set by referring to an index or a key  
-we can loop through the set items using a for loop
-Check if an item is present in the set
  print("orange" in fruitSet)
  print("orange" not in fruitSet)
-To add one item to a set use the add() method
-To add items from another set into the current set, use the update() method
  fruitSet = {"apple", "banana", "cherry"}
  tropical = {"pineapple", "mango", "papaya"}
  fruitSet.update(tropical)
  print(fruitSet)  # 6 items
-To remove an item in a set, use the remove(), or the discard() method
   fruitSet.discard("banana")

Note: If the item to remove does not exist, discard() will NOT raise an error.
      If the item to remove does not exist, remove() will raise an error.
-There are several ways to join two or more sets in Python.
  The union() and update() methods joins all items from both sets.
  The intersection() method keeps ONLY the duplicates.
  The difference() method keeps the items from the first set that are not in the other set(s).
  The symmetric_difference() method keeps all items EXCEPT the duplicates.        

-frozenset is an immutable version of a set.
-elements cannot be added or removed from a frozenset.
  fruits = frozenset({"apple", "banana", "cherry"})

Abstraction
===========
-Abstraction means hiding unnecessary implementation details and showing only the essential features to the user.
-Suppose we create a payment system, The user doesn't need to know the internal implementation


Abstract Class:
-An abstract class is a class that provides a common structure for other classes.
-an abstract class cannot be instantiated directly if it contains unimplemented abstract methods.
-Python provides the abc module for this.
It can contain:
    Abstract methods
    Normal methods
    Attributes
    Constructors
-ABC is the base class used to create an abstract class.
-An abstract method is declared using the @abstractmethod decorator (from abc) and has no real implementation in the base class — it just defines the signature every subclass must follow.
-Any subclass that doesn't implement all abstract methods also becomes abstract and cannot be instantiated either.
-Abstract classes enforce a contract: they guarantee that anything calling a method on a subclass will find that method implemented, without needing to know the concrete class.



Dates
=====
-The datetime module is the standard way to work with dates and times.

-Key classes: date (year/month/day), time (hour/min/sec), datetime (both combined), timedelta (a duration/difference), timezone (UTC offsets).

-Dates are immutable — every operation returns a new object rather than modifying in place.
datetime.now() gives local time; datetime.utcnow() (deprecated in 3.12+) — use datetime.now(timezone.utc) instead for timezone-aware UTC.

-Naive vs aware: a naive datetime has no timezone info; an aware one does. Mixing the two in comparisons raises errors — always be consistent.

-Formatting uses strftime (datetime → string) and parsing uses strptime (string → datetime). Mnemonic: format, parse.

-For real-world timezone handling, use the built-in zoneinfo module (3.9+) instead of pytz.

-timedelta supports arithmetic directly — add/subtract it from dates, or subtract two dates to get a timedelta.

Exception Handling
==================
-An exception is an error that occurs during program execution, disrupting the normal flow. 

-Python stops normal execution and looks for a handler.

-Exception handling lets us anticipate and manage errors gracefully instead of letting the program crash.

-Core keywords: try, except, else, finally, raise.
    The try block lets us test a block of code for errors.
    The except block lets us handle the error.
    The else block lets us execute code when there is no error.
    The finally block lets us execute code, regardless of the result of the try- and except blocks.

-Python exceptions are objects — all built-in exceptions inherit from the base class BaseException, and most user-facing ones from Exception.

-we can define our own exception classes for domain-specific error handling.
